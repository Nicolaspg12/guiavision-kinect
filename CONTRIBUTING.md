# Contribuir

Describe el problema, el equipo y una reproducción sin datos personales. Para cambios, envía una pull request con su propósito y las pruebas realizadas.

Ejecuta `python -m unittest discover -s tests -v` y `python -m compileall -q guiavision tests`. Los cambios sobre profundidad, direcciones, voz o controladores requieren además resultados del protocolo con hardware.

No incluyas credenciales, grabaciones de personas, datasets sin derechos comprobados ni checkpoints de procedencia desconocida. Conserva la atribución y la licencia AGPL-3.0-only. Las contribuciones se reciben bajo esa misma licencia.
